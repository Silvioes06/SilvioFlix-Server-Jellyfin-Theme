# SilvioFlix Server — Jellyfin Theme

Tema personalizado para Jellyfin desenvolvido para o
SilvioFlix Server.

## Características

- Tema preto escuro
- Identidade visual SilvioFlix
- Logo personalizada em PNG
- Azul escuro como cor principal
- Interface moderna
- Visual elegante e minimalista
- Cards de mídia com efeitos discretos
- Sidebar escura
- Scrollbar personalizada
- Interface responsiva
- Compatível com uso em servidor NAS
